# Snow Screen Saver

Полноэкранная заставка с анимацией снегопада, разработанная на C# и Windows Forms (.NET 8).

Проект демонстрирует создание плавной 2D-анимации с использованием встроенных средств Windows Forms, работу с графикой, таймерами и пользовательскими ресурсами приложения.

## Возможности

- Полноэкранный режим без рамок окна
- Анимация падающих снежинок
- Отрисовка пользовательских изображений
- Фоновое изображение зимнего пейзажа
- Частота обновления до 120 FPS
- Двойная буферизация (Double Buffering) для плавной анимации
- Автоматическое переиспользование снежинок после выхода за границы экрана
- Завершение работы по нажатию любой клавиши

## Технологии

- C#
- .NET 8
- Windows Forms
- GDI+ Graphics
- Resource Management (.resx)

## Архитектура проекта

### MainForm

Главное окно приложения.

Отвечает за:

- создание снежинок;
- запуск таймера анимации;
- обновление координат объектов;
- отрисовку кадров;
- обработку пользовательского ввода.
